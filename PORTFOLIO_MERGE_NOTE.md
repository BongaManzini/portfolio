# Portfolio Merge Note

This repository combines two portfolio projects:

1. **Root directory** — `bonga-manzini-portfolio` (Vite + TypeScript, primary)
2. **`legacy-portfolio-reference/`** — Original `Portofolio` (npm) project for reference

The root directory is the **canonical, active portfolio**. The legacy folder is kept for historical reference and content that may be worth migrating.
