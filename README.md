# 💼 Bonga Manzini – Developer Portfolio

A modern, high-performance developer portfolio built with React 19, TypeScript, Vite, and Tailwind CSS, showcasing full-stack web applications, real-time AI security systems, machine learning models, and browser automation suites.

---

## 🚀 Projects Showcased

- **[DeepSentryAI](https://github.com/bongamanzini/deep-sentry-ai)**: Real-time call center defense platform detecting deepfake audio, manipulated video feeds, and anomalous network activity.
- **[FocusFlux](https://github.com/bongamanzini/focusflux)**: Full-stack ADHD and mental wellness web app featuring 8 cognitive training games, grounding exercises, and Google Gemini AI emotional support.
- **[Self-Healing Network System](https://github.com/bongamanzini/self-healing-network)**: Autonomous AI network defense system with real-time threat detection and policy remediation.
- **[ByteCraft – Student Risk Predictor](https://github.com/bongamanzini/bytecraft-student-risk)**: Higher-education predictive analytics platform utilizing Random Forest classification to forecast student dropout risk.
- **[SkyApp – AR Celestial Planetarium](https://github.com/bongamanzini/sky-app)**: Mobile-first 3D celestial star map with camera augmented reality overlay and offline PWA capability.
- **[June 16 – Soweto Memorial Experience](https://github.com/bongamanzini/june16-memorial-site)**: Interactive 3D digital memorial honoring the 1976 Soweto Uprising using React and Three.js.
- **[UNISA Nexus Hub](https://github.com/bongamanzini/unisa-nexus-hub)**: Student resource portal engineered with React, TypeScript, and Shadcn UI.
- **[DevDesk Pro & IT Support Hub](https://github.com/bongamanzini/devdesk-pro)**: Manifest V3 browser automation extension suite for service desk ticket dispatching.
- **[UbuntuSec Awareness Platform](https://github.com/bongamanzini/ubuntu-sec)**: Gamified cybersecurity awareness education platform inspired by the Ubuntu philosophy.
- **[ImageSense – OCR to Excel Pipeline](https://github.com/bongamanzini/imagesense-ocr)**: Automated computer vision pipeline converting scanned documents to Excel spreadsheets.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite 6
- **Styling**: Tailwind CSS, Glassmorphism UI
- **Icons**: Lucide Icons
- **Deployment**: GitHub Pages / Vercel

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
